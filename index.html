How this app works

Use it as a local marking workspace: paste writing, suggest changes, add teacher comments, then export a clean student copy.

1. Add the writing

Use Editing mode to paste or type the student's writing. Paste writing images directly with Cmd+V on macOS or Ctrl+V on Windows; use Add image(s) for task prompt images.

2. Mark in Suggesting mode

Switch to Suggesting mode before editing. New teacher text appears bold green, and deleted student text stays visible in red strikethrough. Right-click a green addition to remove it, or right-click a red deletion to restore the original text.

3. Add feedback comments

Select text to open the feedback window. Choose a feedback type, write an explanation, and paste screenshots into the comment if needed. Drag a pasted writing image corner to resize it, or right-click it to remove it.

4. Use IELTS scores

Enter whole-band scores for the four IELTS Writing criteria. The app calculates the overall score by averaging and rounding to the nearest half band.

5. Save or continue later

The app autosaves the current draft in this browser. Use Save session to keep an editable JSON backup, and Load session to restore it on another device or browser.

6. Export for students

  • Student HTML creates a standalone student feedback page.
  • PDF opens a browser print view. Save as PDF from the print dialog.
  • The CrushIELTS logo is off by default; enable it only if it applies.

Offline use: click Download for offline use, then open the downloaded HTML file whenever you need the app. No server, account, or internet connection is required after download.

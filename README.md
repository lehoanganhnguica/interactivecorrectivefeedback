# Writing Feedback Studio

A single-file browser app for marking student writing with editing mode, suggesting mode, feedback comments, session save/load, image prompts, and standalone student HTML export.

## Use

Open `index.html` in a browser. No build step, backend, or internet connection is required.

## Files

- `index.html` - the complete app
- `README.md` - this note

## Notes

Session files are saved as JSON and can be loaded back into the app. Student exports are standalone HTML files with inline CSS and JavaScript.
